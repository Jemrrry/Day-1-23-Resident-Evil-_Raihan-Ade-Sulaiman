# 📝 Catatan Lengkap Workshop EXPECTIK 2026
**Misi**: Day 1 - Proyek Workshop-26  
**Topik**: Pengenalan Git, GitHub, dan Dokumentasi Teknis

---

## 1. Pendahuluan
Workshop ini membahas tentang pemanfaatan Git sebagai Version Control System dan GitHub sebagai platform kolaborasi dan penyimpanan kode berbasis *cloud*.

## 2. Rangkuman Materi Pembahasan
- **Version Control System (VCS)**: Sistem yang mencatat setiap perubahan file dari waktu ke waktu sehingga versi terdahulu dapat ditinjau kembali.
- **Git vs GitHub**:
  - Git: Alat pengontrol versi yang bekerja secara lokal di komputer.
  - GitHub: Layanan berbasis web untuk meng-host repositori Git di *cloud*.
- **Konsep Repository Publik**: Repositori yang dapat dilihat dan diakses oleh siapa saja di internet tanpa perlu otentikasi atau izin khusus, sangat cocok untuk tugas dan portofolio terbuka.

## 3. Catatan Praktik
1. Mengatur nama dan email pada konfigurasi Git.
2. Menginisialisasi repositori dengan perintah `git init`.
3. Menambahkan berkas ke indeks pelacakan dengan `git add`.
4. Menyimpan perubahan secara berkala dengan pesan commit yang deskriptif.
5. Menghubungkan ke repositori jarak jauh (*remote*) dan melakukan `push`.

## 4. Evaluasi & Refleksi Pembelajaran
Melalui workshop ini, dipahami pentingnya memiliki repositori terstruktur dengan dokumentasi `README.md` yang lengkap. Hal ini mempermudah kolaborator maupun penilai memahami isi dan tujuan proyek.
